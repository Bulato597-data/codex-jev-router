# Global Jev Model Routing

For each **new actionable task that needs a model selection**, first refine the user's request into a concise execution brief. Preserve the requested scope and intent; do not silently add work. If the user is still discussing, correcting, or iterating the task, reflect material changes in the brief and route the latest agreed version before execution. Do not call Jev for ordinary conversation, acknowledgments, status questions, or a continuation that does not change the task or require a new model choice.

Send that approved brief once on standard input to `~/.local/bin/jev-route`, before inspecting files, researching, editing, or acting. Do not add a timed delay. Never send credentials, private keys, tokens, or task text containing secrets to Jev. A new automatic task launch should invoke Jev once regardless of the local keyword lane; explicit user-selected model/lane overrides do not need a Jev call.

Treat `jev.verified: true` as a complete set of validated TypeSafe Noul answers, not a model choice. Jev reports one 0–1 probability per atomic statement; there is no Noul confidence field. Local code applies the catalog's explicit positive (>=0.70), negative (<=0.30), and uncertain-band rules to compose the model and effort, then applies deterministic safety floors. Pause only when that final route comes from a valid composition (`route.source == jev-noul-composed`) and differs from the active desktop model or effort. If the active desktop model or effort cannot be established, treat that as needing manual confirmation and pause. In the pause reply, state the final model and effort, the selected Noul probabilities that led to it, and any local override. Do not describe a Noul value as confidence or as probability of task success. Then make no task calls, file reads, research calls, edits, or implementation steps. Stop so the user can choose the displayed model and effort in the desktop picker and say “continue.” Resume only after that continuation. Never claim the active model changed automatically.

If Jev is not requested, unavailable, malformed, or otherwise unverified, continue under the local routing policy without asking the user to retry or switch models. The desktop default is `gpt-6-luna` at `xhigh`. Use the lightest available model and effort that safely meets the task's quality requirement; raise capability when scope, ambiguity, verification burden, or consequences materially require it.

This helper and its credential access are global to local Codex desktop and CLI chats on this Mac, across projects. A cloud ChatGPT Work runtime cannot access the Mac helper or Keychain. Do not claim Jev coverage in ChatGPT Work unless a separately authenticated remote bridge has been implemented and verified from that runtime.
